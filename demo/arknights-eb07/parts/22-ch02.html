02//T-46:12 地层应力越界与驳回批复

ANOMALY CODE // 异况代码 EB-ERR-4029（地质应力越界）
INSTANT RATE // 瞬时沉降率 12.8 mm/h（超限 32.0 倍）
INFRASOUND // 地音共振频 2.4 Hz 微震持续脉冲 (420s)
RESPONSE STATUS // 处理状态 CDPC 驳回：维持二级观察待机
上午九时四十八分，机架最右侧的蜂鸣器突然尖锐嘶叫，撕破了机房的沉闷。记录纸带滚筒高速旋转，紫色墨水针头在带格标尺上剧烈弹跳：03 号与 11 号孔位深井石英应力计读数失控飙升，沉降速率自 0.04 毫米/日骤增至每小时 12.8 毫米，超过一级警报阈值三十二倍。地下深处溶洞顶板的水听探头同时捕捉到低频次声波震颤——那是数百万吨基岩在巨大抗剪剪切力下发出的呻吟。
我的指尖瞬间冰凉。我依照手册第四条第二款迅速截取应力斜率，打印成特急呈报单《EB-ERR-4029》，加盖红印通过加密专线向市防灾减灾中心（CDPC）提交。
四十二分钟后电传打字机吐出批复，措辞冰冷齐整：“经专家组复核，传感器脉冲系新港区深基坑连续墙注浆施工引发之浅层孔隙水压局部释放，属工程受控沉降。维持二级常规待机，暂不启动防灾疏散警报。严禁擅自发布非确认信息，继续观察。”
深红公章压在末行。我在批复单空白下边缘，用铅笔推演着那条未被采信的剪应力曲线：临界点不在下周，而在今夜。窗外，成群海鸟惊恐成片腾空盘旋哀鸣，迟迟不敢落回防波堤。
