OFFICIAL PROCLAMATION // 法定通告正文 BROADCAST MANDATORY
“全域基岩承载力已达破坏极限。即刻起，红、金、蓝三区启动疏散。全体市民听从民防应急广播（104.2MHz / 780kHz）引导，向北侧跨江生命线分批后撤。”
然而，摊在播报台上的三区时序表是一道无解的数学死局：
红区 // 重化工业港区
POPULATION: 18.4 万人 · 窗口: 4.2 小时
处于沉陷中心。集聚液化烃与光气化工基地，储罐倾斜率破极值。储罐一旦剪切破裂将封死海湾，撤离仅靠单线工矿铁路。
金区 // 老城生活街区
POPULATION: 42.1 万人 · 需求: 14.5 小时
人口最密。深巷狭窄，多为老旧石桥，通行阻尼极大。居民以老幼为主，安全撤离理论耗时十四个半小时。
蓝区 // 行政与滨海新城
POPULATION: 15.6 万人 · 窗口: 2.5 小时
市政等级最高，拥双向八车道高架。但其入桥匝道与金区唯一逃生省道在跨江桥头呈剪刀状交汇死锁。
若三区同时涌向跨江桥，蓝区私家车流将在四十分钟内把金区步行老幼死死卡在引桥下；若扣留蓝区优先老城，红区储罐倾覆的毒气又将吞噬全湾。调度机里满是尖叫争吵。我在发烫的面板前按下广播钮，每句措辞背后都是生与死的冷酷博弈。
