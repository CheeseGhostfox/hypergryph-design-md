04//T-18:05 跨江通道断裂与信标强行并联

CRITICAL FAILURE // 结构失效 白屿二桥 4# 主沉井基桩剪切断开
CHOKEPOINT THROUGHPUT // 咽喉通行能力 0%（主梁垮塌坠江 · 全线阻断）
DISPATCH DIRECTIVE // 调度指令 CMD-FREQ-SPLIT-99（强行切断中波）
OPERATOR DECISION // 操作决断 拒执行 · 强行双频并联 · 烧毁备用机
下午一时五十五分，大地剧烈抽搐。瞭望窗外江心腾起数丈高的泥浆与白雾。白屿二桥第四号深水沉井在巨大剪应力下轰然折断，四百米主梁带着金属扭曲巨响倾覆坠入江底，断口高压电缆迸出数道青白电弧。
通道断了。车队在引桥失控冲撞，将金区仅存的步行便桥死死封堵。指挥中心急电命令《CMD-FREQ-SPLIT-99》：“立即切断金区 780kHz 中波，功率全部汇聚至 104.2MHz 蓝区调频，播报浅滩渡口，优先保全重点车队。”
蓝区私家车配有调频屏显；而断电的金区老街里，四十万平民唯一的工具是两节干电池的老式晶体管中波半导体。切断 780kHz，他们将瞬间坠入无声死渊，无人知道主桥已塌，只能盲目走向绝路。
控制台前并排着红色的“依规切断”与黑色的“强行并联”两枚按键。指挥官在耳机里尖叫催促。我没有碰红色，大拇指重重按下了黑色按键。
配电柜猛地爆出耀眼电弧，备用功放管瞬间熔断焦糊。我以烧毁备用机为代价，将超短波信号强行并入中波天线，为金区保住了九十分钟全功率播报。我在日志写下：“工号 EB-07-04 自主启动双频并联。设备损坏后果与规程责任，由我一人承担。”
