06//T-00:00 终末宣告与全域绝对静默

CITY STATUS // 白屿全域态势 冲积平原沉陷入海 · 城市全域灭灯
WATER LEVEL // 站外潮位 淹没大门石阶第三级（+143.2m）
ANTENNA SWR // 天线阻抗匹配 地网没水 · 驻波比失谐至 ∞
CHANNEL RESPONSE // 空中电波应答 0 个台站 · 全频段底噪 100%
早晨八点整。沉陷到达终局。
浑浊海浪漫过正门石阶第三级，拍打铸铁铅门发出沉闷回响。机房弥漫电解液酸雾与绝缘胶焦味。天线基座沉入水下，放电管跳跃微弱幽蓝电晕。窗外的平原街区已尽数沉入灰黑浪涛，唯余几栋摩天楼尖顶如墓碑刺破水面，破裂的天然气管在海浪中燃烧着残烛孤火。
但在视线尽头，那道黑色的玄武岩山脊高高隆起。漫长的撤离人流如同一条黑色细线，全部跨过了山脊北端的最高关口。他们走过去了。
对讲机里全是纯粹白噪声，无人应答。依照条例第七条第三款，我拿起话筒，发出白屿市在空中的最后一段宣告：
FINAL STATUTORY TRANSMISSION // 全域法定终末宣告
“白屿市全域紧急疏散引导播报结束。当前时间，新历二十六年十月十二日早八点整。全频段关机。”
我松开按键，伸手扳下发射机主刀闸，切断蓄电池母线。
持续七十二小时的巨大电流轰鸣瞬间消失。世界陷入纯粹的绝对静默。只有门外浪涛拍打钢板，一下，又一下。室内唯余吞噬一切的纯黑。我没有站起来，也没有走向那扇无法开启的门。
