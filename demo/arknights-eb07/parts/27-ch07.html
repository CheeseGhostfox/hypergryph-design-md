07//——:—— 起获磁带与未曾寄出的名字

RECOVERY DATE // 打捞归档日期 新历 42 年 4 月 17 日（四十年后）
RECOVERY SITE // 起获遗址地点 白屿市狮子口玄武岩残礁（水下 12m 避难舱）
PHYSICAL OBJECT // 物件技术特征 1/4 英寸开盘磁带 · 铅笔标注「未接天线」
SEARCH VERDICT // 遗骸与人员勘验 未发现任何遗骨与随身物品 · 空白存留
新历四十二年春，地质搜寻组登上退潮时露出海面的狮子口孤礁。站房已风化为残破混凝土空壳。在水下避难舱深处，搜寻队起获了一盘保存完好的开盘磁带（编号 `TAPE-EB07-7`）。封套上留有铅笔划过的字迹：“未接天线”。
MAGNETIC TAPE REEL TELEMETRY // TAPE-EB07-7 SPEED: 7.5 IPS · TRACK: MONO ANALOG
AUDIO TRANSCRIPTION // DECLASSIFIED TAPE TRANSCRIPT

（走带电机嗡鸣与微弱摩擦声……打火机滑动的轻响，随后是一声微弱的吐气声）

“……主发射机停了。天线电缆也拔掉了。外面很安静，除了水浪撞门的声响，什么也听不见。

刚才从窗缝最后看了一眼，山脊路上的人已经全走过了风口。他们走得真慢啊，但确实走过去了。老吴留下的半壶咖啡完全凉透了，不过喝起来居然还行。

这盘磁带不会播出去，它根本没接在发射机上。四五十年后可能没人记得这座城市本来的样子，没人记得老城石桥有多窄，也没人记得大桥塌掉的声音。但总得有人在一切归于泥沙前，给它划上最后一个句号。

电池快放尽了。白屿市全域避难引导播报完毕。记录结束。

工号 EB-07-04。技术员林述。”

（话筒开关弹起的回弹声。人声完整收尾并主动停止）

（磁带继续平稳走动了四分二十秒，记录着机房底噪与海潮声，直至磁带走完停转）

HISTORICAL ARCHIVE VERDICT // 调查结论备忘录
搜寻组在对遗址及周边二百米残骸区进行三次全覆盖多波束声呐扫描后确认： 现场未发现任何人体骨骼、随身生活遗物或救生设备痕迹。去向未明，不作推测判定。 本盘磁带为白屿市档案中唯一完整终结之物理记录。归档定名《未播出的第七段》，列为永久一级历史文献。 空白留存于此。
