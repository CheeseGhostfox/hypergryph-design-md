07//——:—— 起获磁带与未曾寄出的名字

RECOVERY DATE // 打捞归档日期 新历 42 年 4 月 17 日（四十年后）
RECOVERY SITE // 起获遗址地点 白屿市狮子口玄武岩残礁（水下 12m 避难舱）
PHYSICAL OBJECT // 物件技术特征 1/4 英寸开盘磁带 · 铅笔标注「未接天线」
SEARCH VERDICT // 遗骸与人员勘验 未发现任何遗骨与随身物品 · 空白存留
新历四十二年春，地质搜寻组登上退潮时露出海面的狮子口孤礁。站房已风化为残破混凝土空壳。在水下避难舱深处，搜寻队起获了一盘保存完好的开盘磁带（编号 `TAPE-EB07-7`）。封套上留有铅笔划过的字迹：“未接天线”。
MAGNETIC TAPE REEL TELEMETRY // TAPE-EB07-7 SPEED: 7.5 IPS · TRACK: MONO ANALOG
AUDIO TRANSCRIPTION // DECLASSIFIED TAPE TRANSCRIPT

（走带电机嗡鸣与微弱摩擦声……打火机滑动的轻响，随后是一声微弱的吐气声）

“……主发射机停了。天线电缆也拔掉了。外面很安静，除了水浪撞门的声响，什么也听不见。

刚才从窗缝最后看了一眼，山脊路上的人已经全走过了风口。他们走得真慢啊，但确实走过去了。老吴留下的半壶咖啡完全凉透了，不过喝起来居然还行。

这盘磁带不会播出去，它根本没接在发射机上。四五十年后可能没人记得这座城市本来的样子，没人记得老城石桥有多窄，也没人记得大桥塌掉的声音。但总得有人在一切归于泥沙前，给它划上最后一个句号。

电池快放尽了。白屿市全域避难引导播报完毕。记录结束。

工号 EB-07-04。技术员林述。”

（话筒开关弹起的回弹声。人声完整收尾并主动停止）

（磁带继续平稳走动了四分二十秒，记录着机房底噪与海潮声，直至磁带走完停转）

HISTORICAL ARCHIVE VERDICT // 调查结论备忘录
搜寻组在对遗址及周边二百米残骸区进行三次全覆盖多波束声呐扫描后确认： 现场未发现任何人体骨骼、随身生活遗物或救生设备痕迹。去向未明，不作推测判定。 本盘磁带为白屿市档案中唯一完整终结之物理记录。归档定名《未播出的第七段》，列为永久一级历史文献。 空白留存于此。
DECLASSIFIED ANNEX // 解密附件 磁带物性检验与盒内夹存物 · EB07-ANNEX-07
SHEET 07 // 磁带物性检验单 · 实验室编号 LAB-42-0417
[带基]1/4 英寸醋酸纤维素带基，7.5 英寸/秒，单声道。磁粉层完整，无霉变、无拉伸变形。可读段 100%，未做信号增强处理。
[盒内夹存物]无纸条、无照片、无第二件物品。封套铅笔字迹经比对为现场书写，笔压均匀，书写时手部无颤抖。
[归档决定]原件恒温封存，不作消磁与再转录。档案编号 EB-ARCHIVE-4029-VII，等级永久一级。
FINAL DISPOSITION // 终局处置

卷宗至此闭合。磁带仍可读，天线地网仍可临时架设。身为四十年后的调阅者，你对这盘磁带作出最后处置。

本处置已记录于调阅终端，可在清除后重新选定。
ENDING A // 处置结果 · 重新发射 OUTCOME: RE-TRANSMIT

处置令于新历四十二年四月十七日十七时四十分生效：磁带以 7.5 英寸/秒原速回放，经修复后残存的 TX-01 发射机并入临时架设的天线地网，向 104.2MHz 与 780kHz 双频同播，功率 500 瓦，持续四分二十秒。

这是白屿市沉没四十年后，第一次有声音从狮子口方向升起。值班技术员在原地站完全程，没有按下任何一枚中止键。信号越过山脊，掠过已成浅滩的老城石桥，最终散入夜里的电离层，什么也没有留下，只是响过了。

当日值班日志补记一行：录音已播发，接收方一栏填写「全部」。磁带随后重新封装回原盒，编号不变，封套上「未接天线」四字以铅笔划去一道，未撕、未涂改。

那盘磁带在架子上又放了四十年。封套上多了一行铅笔小字：本次已接天线。

ENDING B // 处置结果 · 维持封存 OUTCOME: KEEP SEALED

处置令于新历四十二年四月十七日十七时四十分生效：磁带不作回放，原盒原封退回恒温库房，架位 EB-07-VII，温度 18℃、湿度 45%，年度抽检一次，不作消磁。临时架设的天线当日拆除，地网铜线卷回收库。

现场未留存任何复制件、转录稿或播放记录。调查结论备忘录维持原状，最后一栏仍是那两个字：空白。四十年后收到的这四分二十秒，就这样又被交还给了四十年后的沉默。

库房管理员在新历四十二年度的抽检表上，把这盘磁带的状态勾为「完好·未启用」。表下按规程附一句例注：本件不属于待播素材，不具备启封权限。没有人为它写过申诉。

封套上「未接天线」四个字，此后一直是这座城市最完整的一句话。
